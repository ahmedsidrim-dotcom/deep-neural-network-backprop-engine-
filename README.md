# Deep Neural Network Backprop Engine

A multi-layer perceptron (MLP) deep learning framework built entirely from scratch using Python and NumPy, deliberately avoiding high-level black-box frameworks like PyTorch or TensorFlow.

## Core Architecture
- **Forward & Backward Propagation:** Complete mathematical implementation of matrix derivatives, activation functions, and the chain rule from first principles.
- **Optimized Matrix Operations:** Highly vectorized linear algebra computations using NumPy for efficient multi-dimensional array transformations.
- **Parameter Optimization:** Gradient descent weight updates with configurable learning rates and dynamic layer dimensions.
